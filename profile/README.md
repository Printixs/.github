# 🏢 Printix

Printix is a **cloud print management** platform for organizations. Sign in with **SSO**, release jobs with **pull printing**, and control printers per **site** from a web portal.

## ✨ Key Features

- 🔐 **SSO sign-in** with directory sync
- 🖨️ **Pull printing** release
- 🌍 **Site-based printer control**
- 📊 **Usage reporting**
- 🧩 **Universal driver handling**
- 📱 **Mobile release**
- 🛡️ **Policy rules**
- 🗂️ **Queue administration**

## 🚀 Why Choose Printix?

Pull printing removes abandoned jobs at the tray because nothing prints until a badge or login confirms the release. Site control keeps each office on its own device set.

Reporting and policies are managed centrally, not per machine.

## 🎮 Why Use It?

- **Release jobs** at the device
- **Sign in with SSO**
- **Control printers** per site
- **Review usage**
- **Apply print policies**

## 🧩 Quick Start

1. Connect the directory to Printix.
2. Register printers per site.
3. Set a pull printing policy.
4. Install the client.
5. Release a test job at the device.
